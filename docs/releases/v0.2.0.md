# Aperture v0.2.0 — preview notes

**Status: unreleased. v0.2.0 has not been uploaded to GitHub Releases.** These notes describe the current development version, not the public v0.1.0 download.

## What’s new

### AirDrop activity

Send files from File Tray or Choose Files and follow activity at the notch. Incoming transfers can expand into a preview after import. Sending and receiving have separate expansion preferences, and completed activities clear automatically.

The native macOS Accept/Decline prompt and completion notification remain. The ring shows activity, not a byte-progress percentage.

### Up Next for Apple Music

See the next track’s title, artist, artwork when available, and a countdown ring near the end of a song. Choose a **2–10-second** lead time; the default is **5 seconds**.

Music’s **Playing Next sidebar must be open**. The queue is read from that interface, rather than inferred from playlist order. Repeat-one, paused playback and stale metadata do not trigger the peek. Local artwork lookup has a catalogue fallback with exact track/artist/album matching, regional edition lookup, and caching.

### Screenshot-friendly File Tray

Drop the floating screenshot thumbnail, promised files, and image-only data into File Tray. Temporary screenshot/image sources are retained in Aperture’s local storage, so they remain available after the source disappears and the tray is reopened. Failed imports can show an error instead of silently leaving an empty tray.

## Improvements

- **Live waveform:** six frequency bands replace time-slice loudness sampling. Compact, expanded and lock-screen music glyphs subscribe to the same live service. Changes in loudness and frequency produce distinct responses, and the bars decay during silence.
- **Waveform color:** dark artwork colors are lifted for visibility against the island’s black background; the cover itself stays unchanged.
- **Player layout:** lower artwork placement, a slightly larger expanded waveform, full-width long time labels, and revised spacing with and without volume open.
- **Interaction:** more visible but restrained idle hover feedback, shared artwork geometry, coordinated activity transitions, and reduced-motion handling.
- **AirDrop lifecycle:** improved send completion, interrupted-transfer cleanup, and separation of concurrent send/receive activities.
- **Menu-bar refresh:** launch-time and follow-up checks reevaluate hiding for newly registered app icons. Universal icon reordering is not included.

## Lock Screen music and widgets

The separate Lock Screen music player is an existing Aperture feature, not a newly invented v0.2.0 addition. The current interface includes artwork, track details, seeking, transport controls, shuffle, an output indicator, and optional volume. It offers Glass/Clear styles, paused-track idle duration and vertical placement settings. Battery, connectivity, Focus, Calendar and weather are independently configurable status widgets.

See the [Lock Screen feature guide](../../README.md#your-music-on-the-lock-screen) for the complete explanation and visual demonstration.

## Before release

- Real incoming and outgoing phone-call tests remain deferred. Call controls are experimental and are not counted as verified release features.
- Receiving AirDrop observes macOS lifecycle events; it is not a documented public receive API. Native consent is retained.
- Up Next depends on Music exposing its queue and on metadata/artwork availability. It does not support every media source.
- Animated Apple Music Lock Screen artwork is not included.
- The final v0.2.0 installer still needs to be refreshed and checked before upload. These notes do not publish or replace a release asset.
