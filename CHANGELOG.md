# Changelog

## 0.2.0 — unreleased

**Not uploaded yet.** See the [v0.2.0 preview notes](docs/releases/v0.2.0.md) for feature behavior and release limitations.

### Added

- AirDrop activity at the notch, sending from File Tray or Choose Files, and separate send/receive expansion preferences.
- Apple Music Up Next with next-track metadata, artwork lookup, and a countdown ring. The lead time is configurable from 2–10 seconds, defaulting to 5; Music’s Playing Next sidebar must be open.
- Floating screenshot thumbnails, promised files and image-only File Tray drops, with retained copies for temporary sources and visible import errors.

### Improved

- Live frequency-band visualization and shared updates across compact, expanded and Lock Screen music views.
- Artwork-derived waveform visibility on dark covers.
- Player alignment, expanded waveform size, long time labels and bottom spacing with or without volume.
- Idle hover feedback, artwork transitions and reduced-motion handling.
- AirDrop completion/interruption cleanup and activity ownership.
- Menu-bar hiding reevaluation after new app launches and late status-item registration.

Phone-call integration is experimental and awaits real incoming/outgoing tests. Native AirDrop consent remains in macOS. Animated Lock Screen album artwork is not included.

## 0.1.0

- Compact and expanded Now Playing, Calendar, and Duo views.
- All Media keeps paused sources available, switches to a playing source when the current one stops, and reads compatible browser video controls.
- Four appearances, live notch calibration, and optional trackpad haptics at tuning steps.
- File Tray with drag and drop, horizontal scrolling, and hover-to-remove.
- Grouped menu-bar hiding with an arrow to reveal items and an adjustable idle timer.
- Bluetooth device icons, Focus notifications, Gaming Focus, and battery indicators.
- Separate Lock Screen music player and status widgets, an unlock animation, and GitHub release checks.
